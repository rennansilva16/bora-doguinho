# Histórico por fase

Cada arquivo `fase-XX.md` reúne o planejamento preservado, o andamento, as
decisões, as validações e as pendências daquela fase.

Não criar arquivos de fases futuras antes de existir planejamento aprovado para
elas. Ao concluir uma fase, preservar seu arquivo e atualizar `../HANDOFF.md`
para apontar para a próxima.
